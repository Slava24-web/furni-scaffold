## Технический долг, заведённый осознанно

- `AssetLoader.evictIfNeeded` не считает реальные байты текстур — `textureBytes`
  всегда 0. Нужен подсчёт при загрузке KTX2.
- `SnapEngine` не строит цели из стен — `setTargets` вызывается пустым массивом.
- Миграции документа сцены пусты: при первом изменении схемы обязательно
  добавить миграцию, иначе сохранённые сцены перестанут открываться.
- Нет WebSocket для совместного редактирования (FR-PLN-15, P2).

## Найдено при первом запуске проекта

- `Telemetry.record` вызывается на каждый тик rAF независимо от того,
  был ли рендер. При включённом рендере по требованию (`needsRender`)
  простаивающие кадры завышают fps: гейт может стать зелёным на сцене,
  которая на самом деле рисуется медленно. Считать fps только по кадрам,
  где реально был `renderer.render`.
- Нет интеграционных тестов API и проверки изоляции тенантов — сейчас
  `pnpm test` в `apps/api` и `apps/web` проходит с `--passWithNoTests`.
  Это заглушка, а не готовность: RLS не проверена ни одним тестом.
- `pnpm size-limit` в CI упадёт: в конфиге есть запись про
  `packages/embed/dist/embed.js`, а самого пакета `packages/embed`
  в репозитории нет. Либо создать пакет, либо убрать запись до фазы 1.
- Камера неподвижна: `orbitCamera`, `panCamera`, `zoomCamera`
  в `useSceneEditing` — пустые заглушки, жесты до них доходят вхолостую.
- Выделение объекта не работает: `hitTestSelection` всегда возвращает
  false, ветка `tap` не делает raycast. Перетаскивание недостижимо.
