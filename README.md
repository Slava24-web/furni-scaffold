# Furni

SaaS 3D-конфигурации и планирования мебели для мебельных магазинов.

- Полное ТЗ: `docs/SPEC.md`
- Правила разработки: `CLAUDE.md` (читаются Claude Code автоматически)
- Что делать дальше: `docs/BACKLOG.md`

## Запуск

```bash
pnpm install
cp .env.example .env
pnpm db:up          # postgres, redis, minio в docker
pnpm db:migrate     # миграции + RLS-политики
pnpm dev
```

Требуется Node 22+, pnpm 9+, Docker. Для пайплайна ассетов дополнительно Blender 4.x.
